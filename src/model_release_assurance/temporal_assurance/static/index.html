What this demonstrates

The local broker keeps privacy spending across model releases, binds delivered bytes to the decision, and blocks releases that would exceed the budget.

What the scope covers

One disability bit per public benchmark record, with other inputs fixed. This is attribute DP, not full-record or longitudinal citizen privacy. A finite attack is not an optimal adversary.

Why reuse matters

Reusing a cached randomized bit is post-processing. Independently renewing its noise spends additional budget. Fresh and cached histories here have different total budgets.

DATA TO RELEASE / LIVE LOCAL WORKFLOW

A controlled path to model release.

Bind a model to its data and DP channel, attach the required red-team report, run the release checks, record a local operator decision, and commit its privacy charges before delivery.

The registry contains existing trained models. This workflow checks their registered provenance before export; it does not run new training. A local operator review accepts the declared attribute-DP scope, not a broader privacy or legal guarantee.

    Read the results within their scope

    • The replay reuses 40 distinct artifacts from a 160-fit source bank. One hundred release attempts are not one hundred new model fits.
    • The first two releases combine different SLM architectures on training datasets with 50% overlap.
    • The linked-score attack receives actual per-record scores in addition to model access. The query-only attack does not.
    • Training set, model family and sequence position vary together in one prescribed order. This does not isolate a causal effect of overlap or architecture.
    • Rounded and label-only charts are restricted, counterfactual views. The actual recipient package contains full-precision scores.
    • The dates are simulated and the cohort is fixed. This is not a Singapore agency deployment or a lifelong privacy guarantee.
