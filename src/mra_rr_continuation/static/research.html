Inspect the frozen evaluation specification
Mandatory tasks and split
Predict fresh coordinates X1 and X2. Four registered training records (000, 002, 005, 007); four held-out records (001, 003, 004, 006). Labels and record IDs are excluded from model features.
Comparable fitting rule
All routes use affine ridge regression with two public covariates, an unpenalized intercept, slope penalty λ = 1, four training rows, no tuning and predictions clipped to [0, 1]. Public-only learning uses a separate four-row public labeled auxiliary cohort.
Fixed decoding
Optimal continuation: T(z) = (24z − 7)/10. Independent joint RR at k = L/d = 3: T(z) = 3z − 1. Uniform p = 1/2 has a singular decoder and is not evaluated.
Primary decision rule
Mean held-out Brier loss; lower is better. Each task must improve expected Brier by at least 1/100 against each comparator. Both mandatory tasks and both comparisons must pass. This illustrative margin is not an agency default.
Exact integration
Enumerate all 256 possible four-row pair-valued training blocks per randomized law using exact fractions, conditional on this saved retained history. No Monte Carlo confidence interval is used.
Variation and diagnostics
Exact 2.5% and 97.5% predictive loss quantiles describe mechanism variation on these fixed records; they are not confidence intervals. Exactly 128 seeded simulations per randomized route are exploratory descriptive diagnostics and never determine admission.
Operational usefulness
Not evaluated. Owner-justified margins, private execution and authoritative cross-system disclosure history remain pending. Release authorization effect: none.

Full research running guide

Start here

  1. Create a public run

    Select Optimal continuation and click Create public run. The server registers a new fictional synthetic cohort and stable shared history, then creates eight fixed synthetic vectors, a retained binary RR response, a public request plan and a certificate. The model cases and saved training evidence remain separate.

  2. Inspect the binding

    Open Inspect bound inputs and declared premises. For the optimal example, r = 2, d = 3, L = 9 and τ = 2/3. Download the retained law, responses, history and request plan to inspect their exact contents. The checker uses these registered inputs rather than accepting a candidate's own context as proof.

  3. Verify the certificate

    Click Verify certificate. The expected optimal result is marginal label correctness 17/24, with conditional correctness 13/18 when the old response is correct and 2/3 when it is wrong. Both strata meet the floor. All arithmetic in the checker uses exact fractions.

    Click Try a tampered certificate, then verify again. The edited candidate must be rejected. Restore saved certificate and verify to return to the valid example. A rejection is a failed candidate check, not a finding that the registered mathematical problem is infeasible.

  4. Draw and inspect one conditional block

    After a valid feasible or optimal certificate, click Draw conditional block once. The server checks the displayed revision and history head, then atomically reserves the shared history before drawing. Each row uses its complete preexisting vector and actual retained response. Inspect all eight sampled blocks and download the output. Reloading or opening the saved run displays the same block. Redeliver saved block returns its exact bytes without another informative draw. Select Create alias of this history to create another run ID for the same synthetic cohort. The retained response, history ID and committed output stay the same; another informative draw is refused.

    If an attempted draw leaves an incomplete reservation, every alias stays blocked across restarts. Preserve that evidence. Only a deliberately new fictional public cohort is suitable for another local experiment; aliases never recover by drawing replacements. A new protected draw in a real deployment would require a new complete joint-law analysis and accounting.

  5. Fit and evaluate the saved block

    Inspect Public Usefulness and its frozen specification before drawing. After saving a block, select Fit and evaluate saved block. Review the exact expected-law Brier comparisons, task decisions and the separate realized model scores. Public-only uses a separate labeled auxiliary cohort; independent RR uses the matched joint ratio L/d. The illustrative gain margin is 1/100 against each comparator on both mandatory tasks.

    Download model coefficients, predictions, diagnostic simulations and the reproducibility manifest. Repeating evaluation or reopening the saved run reuses the same completed block and result. An interrupted evaluation reservation stays blocked and retains evidence. Runs created before prospective Phase 2 registration remain readable but require a fresh public run for this experiment.

  6. Try the two boundary examples

    Infeasible floor uses d = 3, L = 9, r = 2, τ = 3/4. Its certificate can verify the infeasibility claim, but the sampler stays disabled because no channel meets both floors. Uniform boundary uses r = 2, d = L = 1 and τ = 1/2, with exact marginal and conditional correctness 1/2. Random outputs differ across new public runs. Uniform sampling remains available, but its marginal p = 1/2 makes the fixed unbiased decoder singular; usefulness is not evaluated. Infeasible certificates never enable certified fitting.

What this experiment establishes

An accepted certificate establishes its exact channel claim under the registered mathematical declarations. The sampler demonstrates one conditional label block for that channel. Phase 2 fits public synthetic affine ridge models from that saved block and computes exact finite-benchmark usefulness. It does not clear a model or establish general, protected-data or operational usefulness.

The public task-usefulness gate uses an illustrative frozen margin and exact finite integration. Phase 3 adds shared local history and atomic reservations across aliases, processes and restarts for the declared single-continuation law. The independent authoritative agency service, cross-system citizen scope and production execution qualification remain pending. The separate local witness exercises custody checks and is not an independently administered authority.
