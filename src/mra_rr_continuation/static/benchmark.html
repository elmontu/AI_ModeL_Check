Four mandatory public tasks

All domains retained

Each task uses 512 training, 512 disjoint clean auxiliary and 512 held-out records. Selection uses keys and fixed hash priorities. Row disjointness does not establish person or household disjointness.

Inspect source provenance and pinned bytes

The prepared source matrices and transformations are historical. Matching hashes identify retained inputs; they do not independently validate reconstruction from raw agency data.

Preregistered specification

No tuning or optional stopping
Candidate and alternatives
Optimal continuation with r = 1, d = 3, L = 9 and τ = 2/3. Compare with clean public-only learning on separate auxiliary rows and independent RR at fresh ratio L/d = 3. Alternatives are public simulations, not additional protected releases.
Shared learner
Affine ridge regression on fixed one-hot categorical features, unpenalized intercept, slope penalty λ = 1 and predictions clipped to [0, 1]. No identifiers, retained bit, response or training truth enter the randomized learner. Test truth is used only for scoring.
Eight mandatory comparisons
Mean held-out Brier loss; lower is better. Gain is comparator loss minus continuation loss. Each task must improve expected loss by at least 0.01 against both alternatives. This provisional public research margin has no service-owner approval.
Conditional integration
Exactly 4,096 paired repetitions per task, conditional on one persisted retained RR response. Simultaneous two-sided Hoeffding intervals across eight gains use α = 0.05 and range [−1, 1]. Lower bound ≥ margin passes; upper bound < margin fails; overlap is inconclusive. Every comparison must pass.
Interval interpretation
These intervals quantify Monte Carlo integration on fixed rows and retained responses under ideal independent uniform tickets. Seeded NumPy PCG64 is a reproducible computational approximation, not a mathematical iid proof. Population uncertainty is not evaluated.
Separate descriptions
Loss percentiles describe mechanism variation. The first preregistered replicate provides reference-model coefficients, predictions and losses. Those realized scores never determine the expected-gain criterion.
Scope
Historical public labels, bounded samples and domain coverage only. The original synthetic toy benchmark remains separate. Operational usefulness: not evaluated. Release authorization: none.

Public benchmark running guide
Start here

        
    
          
  1. Inspect the fixed public tasks
    Read each task outcome, historical period and public covariates. Open source provenance and the machine-readable specification. These retained categorical samples cover four task domains; they do not establish population representativeness, fresh audit status or person-disjoint panels.
    2. 
          
  2. Register before evaluating
    Select Register fixed benchmark. Registration binds the frozen plan, source snapshots, key-only row selection and runtime before evaluation. The candidate, alternatives, 512-row splits, 0.01 provisional margin and 4,096 repetitions cannot be changed from the page. The registration is local custody, not an independently administered preregistration service.
    3. 
          
  3. Run all mandatory comparisons
    Select Run fixed benchmark and leave the page open while it computes. Each task saves one simulated retained response, verifies the exact channel certificate, then uses the same fixed learner across all three routes. The experiment conditions on the actual retained response. The marginal decoder can be biased under that conditioning; resulting losses are retained without tuning or replacement draws.
    4. 
          
  4. Read gains and uncertainty
    Review all eight comparisons. A comparison passes only if its simultaneous lower gain bound reaches 0.01; an upper bound below 0.01 fails; an overlapping interval is inconclusive. All eight must pass for an overall pass. The seeded integration and ideal iid interpretation are stated beside the results. Descriptive reference-model scores and mechanism percentiles appear separately.
    5. 
          
  5. Inspect and reopen saved artifacts
    Download coefficients, predictions, losses and reproducibility records. Choose a saved registration and Open saved benchmark to inspect it later. Reopen saved results validates and returns the intact completed artifacts. Verification may replay the same fixed computation; it never selects a new history, seed or study. If a reservation is incomplete, preserve its evidence; the page will keep execution blocked across restarts.
