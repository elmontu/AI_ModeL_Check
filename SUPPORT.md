# Support

Model Release Assurance is an alpha, offline reference implementation. It is not an accredited government service and is provided without an operational service-level commitment.

## Public issue tracker

Use GitHub issues for reproducible defects, documentation corrections, and bounded feature proposals that can be demonstrated with synthetic or public data. Include the package version, affected command or contract, expected result, actual result, and a minimal reproduction.

Do not submit agency data, private model artifacts, credentials, signing material, or sensitive attack details.

## Security and sensitive matters

Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities or decision-integrity failures. Security matters must not be reported through a public issue.

## Scope

Maintainers can review defects in the reference implementation and its published contracts. Deployment architecture, accreditation, policy approval, production key management, and agency-specific risk acceptance remain the adopter's responsibility.
