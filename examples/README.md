# Executable examples

The root JSON files are current executable requests for the Version 0.5 assurance engine. `examples/evidence/` contains evidence objects referenced by those requests.

- `request.json` and `optimization-request.json` use the current v2 assessment and optimization contracts.
- incomplete-portfolio, multinomial, and protocol examples use their separately versioned v1 or v1.1 contract families.

Files under `output/assessments/` are generated demonstrations, not authoritative empirical results. The sealed experimental record is under `output/reproduction/`.
